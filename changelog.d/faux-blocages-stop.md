- fix(hosts): le `Stop` d'un profil gouverné ne refuse plus une session qui n'a fait que lire, et compte toujours ses vraies écritures. Ne comptent plus : une redirection vers un brouillon hors projet faite par un lecteur ou un écrivain connu (`cat >`, `cp`, `tee`…), une commande dont chaque segment est une vérification (`pytest`, `ruff check`, `tsc --noEmit`…, jamais avec `--fix`, `format` ou `--basetemp`), `TodoWrite`. Comptent toujours, pour la session comme pour ses sous-agents : `make`, un script, `git apply`, `patch`, un interpréteur, un mot illisible, une écriture relative quel que soit le `cwd`. Le refus « Clôture hors tâche » revient tous les 10 nouvelles écritures (option de profil `options.unattached_reblock_after`) ; entre deux, une ligne non bloquante ; un journal de session réécrit pour acquitter plus qu'il ne compte ne désarme rien. Les rappels identiques (« aucune tâche en cours », « Écriture enregistrée », « code interprété », « gate fini, shadow », « tâche encore proposed ») ne sont dits qu'une fois par session ou quand leur état change ; l'avertissement de code interprété n'est plus doublé en `systemMessage`
