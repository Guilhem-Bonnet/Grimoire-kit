# Changelog

L'historique complet, version par version, est le fichier [`CHANGELOG.md`](https://github.com/Guilhem-Bonnet/Grimoire-kit/blob/main/CHANGELOG.md) à la racine du dépôt : c'est la seule source. Cette page n'en garde pas de copie, qui prendrait du retard.

Les ajouts non publiés y sont sous le titre `[Unreleased]`. Pour savoir si une commande décrite dans ce manuel existe dans la version installée, compare avec `grimoire version`.
