# Voix de référence du clonage vocal

- `reference-fr.wav` : voix de référence française pour le moteur de synthèse `qwen3-tts-clone`.
- `reference-fr.txt` : sa transcription exacte, que le moteur fournit avec l'audio.

Provenance : voix entièrement synthétique, générée avec Qwen3-TTS (modèle sous licence Apache-2.0).
Aucune personne réelle n'a été enregistrée ni imitée.

Le réglage `voice.tts.voice` peut désigner un autre fichier WAV local (avec un `.txt` voisin
portant sa transcription) qui remplace cette référence.
