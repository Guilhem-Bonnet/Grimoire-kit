Dans tes outils. Sur ta machine.

La même règle, écrite une fois, rendue pour chaque hôte. Ce qu'un hôte ne sait pas exécuter est déclaré, jamais caché.

  • Sans hooks, la règle est écrite dans le fichier d'entrée et ne s'oppose qu'en CI.
  • Le kit et son cockpit tournent sur ta machine.

Trois commandes.

La première installe le kit, la deuxième équipe ton dépôt, la troisième rend le gate bloquant.

$ uv tool install grimoire-kit
$ grimoire init . --lite -y
$ grimoire standard init . --profile governed
